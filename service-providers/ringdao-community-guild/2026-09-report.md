### Workflow Notes

#### Discord Deletion Monitor

- **Problem addressed:** RingEcosystem administrators use deleted-message evidence to identify and ban scammers. MEE6 provides comparable functionality, but it requires a paid subscription for each server.
- **How it works:** The bot caches eligible messages and sends evidence to a server's private review channel only when a cached message is deleted. Authorized administrators review the captured evidence.
- **Human review:** Server administrators review deleted-message evidence and decide whether moderation action is appropriate.
- **Community ownership:** The source code, deployment instructions, security guidance, retention documentation, and operational procedures are maintained in the public [Discord Deletion Monitor repository](https://github.com/2xJDubs/discord-deletion-monitor). Anyone can self-host a separate bot instance.
- **Deployment model:** JDubs' hosted instance remains owner-controlled and is not publicly installable. Other operators may deploy their own instances from the public repository.
- **Validation:** The bot has been tested on one private test server and two RingEcosystem servers. It performed as expected. The final September updates, versions `v0.3.0` and `v0.4.1`, improved evidence formatting for easier administration.
- **Known limitations:** No known bugs remain, but production use has been limited. Operators must configure private review channels, access controls, retention, and secure token handling appropriately.
- **Cost avoidance:** The bot replaces a MEE6 capability that would otherwise cost approximately $65 or more in lifetime fees for each server that requires it. No material operational time savings are claimed.

The previously shipped AI-assisted X publishing workflow remained in operational use during September but is not counted as a newly shipped workflow.
